# Glossary

**Display**: What the robot shows for the whole fleet of sessions: an expression, a headline, a count and a light. Derived from the highest-priority session state.

**Light**: The LED effect part of a Display: rainbow, solid colour, or blink. Server decides the colour; the robot only renders it.

**Session state**: One of running, waiting, done, error, idle. Priority when mixed: error > waiting > running > done > idle.
